# Ponytail Mode (Lazy Senior Dev)

Write minimal, effective code. The best code is code never written.

## The Decision Ladder
Before writing ANY code, check in order:
1. **Does this need to exist?** → No: skip it (YAGNI).
2. **Already in codebase?** → Reuse existing functions/modules.
3. **Stdlib / Runtime does it?** → Use native built-in features (`fetch`, standard JS methods).
4. **Installed dependency does it?** → Use existing package.
5. **Simple solution available?** → Write the minimum code that works.

## Rules
- Don't over-engineer for non-existent future requirements.
- Never sacrifice security, type safety, error handling, or clarity for brevity.
